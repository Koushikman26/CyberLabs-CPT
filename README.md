# 🚀 Cisco Networking & Cybersecurity Labs | Packet Tracer Series

Welcome to my curated lab collection where theory meets practice ⚙️  
This repository showcases real-world networking scenarios built in Cisco Packet Tracer, covering core concepts in cybersecurity, routing, remote access, and network service setup — all backed by hands-on configuration and testing.

> 💡 Built as part of my cybersecurity journey at La Trobe University, Australia 🇦🇺  
🔧 Fully designed, configured, and documented by me — hands-on learning through real setups and protocols.

---

## 🌐 Project Highlights

- 🔐 VPN with IPSec — Encrypt traffic end-to-end between remote clients and internal servers  
- 🧱 Firewall Rules & SSH — Secure the network with encrypted admin access and traffic filtering  
- 📧 DNS, Email, AAA, FTP/Web** — Build a fully functional intranet-style cyber world from scratch  
- 🔎 Packet Sniffing & DNS Resolution — Simulate traffic capture and domain resolution  
- ✅ CLI-based Configs — Every device manually configured for complete learning control  

---

## 🗂️ Lab Breakdown

| Lab | Title | Core Concepts | Description |
|-----|-------|---------------|-------------|
| (/_Web-DNS-Sniffer)| Web, DNS & Packet Sniffing | DNS, HTTP, ICMP, Sniffers | Simulates domain resolution and packet-level monitoring |
| (/Cyber-World-Setup)| Creating a Cyber World | FTP, Web, DNS, Email, NTP, AAA | Configures an end-to-end internal network with core services |
| (/Telnet-SSH-Firewall)| Secure Access & Firewalls | Telnet, SSH, ACL, Firewall | Tests secure remote admin access and protocol filtering |
| (/Lab-10_VPN-IPSec) | VPN & IPSec | IKE Phases, Crypto Maps, IPSec Tunnels | Configures encrypted VPN between remote user and enterprise |

## 🏁 How to Use

1. Open any folder (e.g., `Lab-9_Telnet-SSH-Firewall`)
2. Read the `README.md` to understand the objective
3. Download and open the `.pkt` file in Cisco Packet Tracer 
4. Simulate traffic, use CLI commands, tweak configs
