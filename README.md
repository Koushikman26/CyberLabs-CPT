# DNS and Packet Sniffing in a Dual-Network Setup

This lab explores basic web and DNS setup, and introduces packet sniffing.

## 🔍 Key Highlights:
- Configured two subnets and DNS server
- Accessed websites via IP and domain (DNS tested)
- Sniffer configured using a hub between routers
- Captured and analyzed ICMP packets

📡 Great insight into traffic flow and DNS resolution.
