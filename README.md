# Secure Remote Access with Telnet, SSH, and Basic Firewall

This lab involves secure router access and basic firewall rules.

## 🔐 Key Tasks:
- Enabled Telnet (unencrypted) and tested access
- Upgraded to SSH for encrypted remote access
- Configured domain, RSA key, and user credentials
- Implemented firewall rules to block ICMP (ping)

💡 Practical understanding of secure remote management and traffic filtering.
